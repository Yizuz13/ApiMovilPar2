# ApiMovilPar2 - Gestor de Inventario de Productos

Aplicación móvil desarrollada en **Android Studio** utilizando **Java** que implementa una arquitectura completa de operaciones **CRUD** (Create, Read, Update, Delete) con persistencia de datos local mediante **SQLite**.

## ?? Autor
- **Nombre:** Jesus Perez
- **Repositorio:** [ApiMovilPar2](https://github.com/Yizuz13/ApiMovilPar2.git)

## ?? Funcionalidades (CRUD)
- **Create:** Registro de nuevos productos con validación de campos (nombre, categoría, precio y stock).
- **Read:** Visualización de la lista de productos mediante un RecyclerView.
- **Update:** Edición de datos de productos existentes.
- **Delete:** Eliminación de productos con confirmación visual.

## ??? Tecnologías utilizadas
- **Lenguaje:** Java
- **IDE:** Android Studio
- **Persistencia:** SQLite (SQLiteOpenHelper)
- **Control de Versiones:** Git / GitHub
